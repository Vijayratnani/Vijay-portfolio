- **A stateful conversational session API** turns every channel's messages into one shared state machine for the deposit workflow.
- **Deposit-lifecycle REST APIs**, including customer lookup with fallback to an external system.
- **Request-security middleware** for externally exposed integration endpoints, in a network-segmented deployment.
- **Packaging and deployment automation**, including automated certificate provisioning for an installation-free setup.

## Security

End-to-end authentication and account security: **JWT auth**, **password policy and history enforcement**, a **custom CAPTCHA service**, and **rate-limited OTP verification**.

## Key decisions

- **One shared state machine for every channel**, instead of a separate flow per channel.
- **Dual-database support (PostgreSQL and MS SQL Server)**, so the same backend service runs on both cloud and on-premise targets.
